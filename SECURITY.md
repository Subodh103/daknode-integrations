# Report a vulnerability privately

Email **support@daknode.com**, subject **Security report**. Do not put exploit
details, credentials or customer data in public issues. Include the affected
package/version, minimal synthetic reproduction, impact and redacted evidence.
Rotate exposed credentials; do not include them in the report. Ask for a suitable
transfer method before sharing sensitive material; no encryption key is listed.

Use only systems and accounts you are authorized to test. Stop before accessing
other tenants' data or disrupting service. This reporting path grants no testing
permission and promises no response deadline, bounty or legal safe harbor.

Service policy: https://daknode.com/security/reporting/ (after website release).
This repository's MIT license covers its integration material, not the service,
SDK or MCP implementation. Reporting does not change that boundary.
